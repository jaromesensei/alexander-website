# אלכסנדר — אתר ציבורי

אתר תדמית והזמנות למסעדת ההמבורגרים "אלכסנדר" בנהריה. Next.js + Supabase,
עם CMS מובנה לניהול תפריט/גלריה/הגדרות ותרגום חי של התפריט לכל שפה.

מסמכי הפרויקט: `CLAUDE.md` (מוסכמות ואדריכלות), `ROADMAP.md` (סטטוס),
`supabase/README.md` (הקמת Backend).

## התחלה מהירה

```bash
npm install
cp .env.example .env.local   # ומילוי ערכי Supabase + Claude
npm run dev
```

פתחו [http://localhost:3000](http://localhost:3000). ניהול תוכן: `/admin/login`.
